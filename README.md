# html-scanner-program
Program python sederhana untuk scan suatu website untuk kebutuhan pembelajaran data mining, contohnya kalau mau scrapping suatu website maka perlu tahu strukturnya, nah program ini menyediakan struktur itu untuk membuat kode scrapping berikutnya.

program ini dibuat untuk belajar, dan program ini haruslah digunakan dengan bijak, dan boleh digunakan jika teman-teman mau pakai, serta kalau ada saran atau ide bisa didiskusikan lewat issue :).
